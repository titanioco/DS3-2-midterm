## Included components

- `Registro`: stores the record data, priority, parent, and status
- `ArbolGeneral`: n-ary tree with traversal, height, leaf counting, and cancellation logic
- `BST`: basic BST-style registry wrapper
- `AVL`: AVL-style registry wrapper
- `BinaryHeap`: max-priority heap used for next-task selection
- `Main`: command-line controller for the required operations

## Compile and run

From the project root, compile the source files into the output directory. Use
the commands for your shell; the Bash command is not compatible with Windows
PowerShell.

For Bash (Linux, macOS, or Git Bash):
```bash
javac -d out $(find src/main/java -name "*.java")
java -cp out com.ds3midterm.Main
```

For Windows PowerShell:

```powershell
New-Item -ItemType Directory -Force .\out | Out-Null
$sources = Get-ChildItem -Path .\src\main\java -Recurse -Filter *.java | ForEach-Object { $_.FullName }
javac -d .\out $sources
if ($LASTEXITCODE -ne 0) { throw "Compilation failed; the application was not started." }
java -cp .\out com.ds3midterm.Main
```
