# DS3-2 Midterm - Java Backbone

This repository contains the core Java backbone for the exam assignment and provides a clean multi-file structure for the rest of the team to extend. It includes the base model, the general tree, and the CLI integration layer required by the project specification.

> This project backbone was created and refined with AI assistance to accelerate scaffolding, logic implementation, and GitHub-ready documentation.

## Included components

- `Registro`: stores the record data, priority, parent, and status
- `ArbolGeneral`: n-ary tree with traversal, height, leaf counting, and cancellation logic
- `BST`: basic BST-style registry wrapper
- `AVL`: AVL-style registry wrapper
- `BinaryHeap`: max-priority heap used for next-task selection
- `Main`: command-line controller for the required operations

## Compile and run

From the project root, compile the source files into the output directory:

```bash
javac -d out $(find src/main/java -name "*.java")
java -cp out com.ds3midterm.Main
```

On Windows PowerShell, use:

```powershell
javac -d out (Get-ChildItem -Recurse -Filter *.java src/main/java | % { $_.FullName })
java -cp out com.ds3midterm.Main
```
